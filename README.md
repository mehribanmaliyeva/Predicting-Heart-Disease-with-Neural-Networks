# Heart Disease Prediction using Neural Networks

## Introduction
This notebook demonstrates how to build and train a Neural Network model for binary classification using a tabular dataset that contains both numerical and categorical features.

Unlike unstructured data such as images or text, tabular datasets are usually stored in CSV format. Therefore, this project covers the complete workflow from:

- Loading CSV data
- Exploring and preprocessing the dataset
- Encoding categorical variables
- Training a Neural Network model
- Evaluating prediction performance

The goal is to predict whether a patient has heart disease based on medical attributes.

---

# Dataset Overview

The dataset contains information about **303 patients**, where:

- Each row represents one patient
- Each column represents a medical feature
- The `Target` column is the label we want to predict

The task is a binary classification problem:

- `1` → Patient has heart disease
- `0` → Patient does not have heart disease

---
# Expected Outcome

By the end of this project, we expect to build a Neural Network model capable of predicting the presence of heart disease based on patient medical data.

The trained model should be able to:

- Classify patients into heart disease or non-heart disease categories
- Learn meaningful patterns from both numerical and categorical features
- Achieve reliable prediction accuracy on unseen test data

Additionally, this project will provide practical experience in:

- Data preprocessing for tabular datasets
- Feature scaling and encoding
- Building Neural Networks using TensorFlow/Keras
- Evaluating classification models using performance metrics

The final result will be a complete end-to-end machine learning pipeline for healthcare prediction tasks.
